# 고수를 제거해주세요

대학생의 수면시간이 학업성취도에 미치는 영향

팀명: 고수가 필요하다면 제거해주세요

구성원: 백승헌, 임예지, 조성진

역할

조장: 조성진 (발표 및 자료조사)

팀원: 백승헌 (자료조사)

팀원: 임예지 (자료조사)



1주차에서 정한 관심 주제: 2024년 대학생의 하루 평균 수면시간이 6시간 미만 여부가 학업 성취도에 어떤 영향을 미치는가   

사용 예정 데이터
- 대상: 대한민국 20대 대학생 (재학생 및 휴학생)
- 노출: 하루 평균 수면시간 6시간 미만 여부 (부족 노출군 vs 6시간 이상 충분 수면군)
- 결과: 학업 성취도 (직전 학기 학점)
- 시간: 2024년도
